제출 폴더: [`week12/`](week12/)

저장소 주소: https://github.com/Bobin3535/ai-programming-week11

### 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 수업에서 배포된 실습 자료. 원천 데이터의 별도 출처와 라이선스는 배포 안내에 기재되어 있지 않습니다. |
| 파일 | `week12/scores_2026.csv` (헤더 제외 114행, 5열), UTF-8 |
| 열 설명 | 학번(학생 식별자), 이름(학생 이름), 반(반 구분), 과목(프로그래밍·영어·수학), 점수(0~100 정수여야 함) |
| 빈 칸 처리 | 점수가 비어 있는 6행은 제외합니다. 점수를 추정해 채우면 실제 관측값과 구분할 수 없고 평균·합계에 근거 없는 값을 섞게 되기 때문입니다. |
| 중복 처리 | 모든 열이 완전히 같은 행은 하나만 남깁니다. 동일 기록을 여러 번 세어 점수에 중복 가중치가 생기는 것을 막습니다. |
| 이상값 처리 | 반·과목 앞뒤 공백은 제거해 범주를 통일합니다. 점수가 0~100 밖인 4행은 유효한 성적 범위가 아니므로 제외합니다. |

### 실행 및 검증

`week12/` 폴더에서 다음을 실행합니다.

```bash
python3 -m pip install -r requirements.txt
python3 -m pytest -q
```

정제·진단·분석 함수와 제출 워크시트, 원본 입력 자료는 모두 `week12/`에 있습니다. 테스트는 정제 후 100행, 반 종류, 그룹 합계, mini.csv 손계산 결과, 단계별 행 수, 원본 보존을 확인합니다.
